# Versioning

The marketplace tracks every version you publish. Old versions stay installable until you revoke them. Brands can pin specific versions or float to "latest within a major."

This page covers:

- Semver expectations — major / minor / patch and what the platform reads into each
- Peer dependencies — pinning to a major (`^3.0.0`) vs an exact version
- Deprecating a version without revoking it — soft-flag, brands see a warning
- Tier transitions across versions — your 1.0.x can be `beta`, your 2.0.0 can request `verified` review
- How brands install — version pin vs auto-upgrade behavior, and what they see in the dashboard
