# Badges

The trust badge on your package detail page is the first thing a brand sees. There are four tiers, and which one you get is driven by who you are, what your package looks like, and how it's been running.

This page covers:

- **Internal** — OPVS-owned or established partner, signed by OPVS CA, no public-catalog listing
- **Beta** — published but opted-in per brand; default for pre-1.0 packages and any controversial entitlement asks
- **Verified** — human-reviewed, required docs present, security checks clean, 30 days of stable telemetry (Phase 2)
- **Community** — auto-checks only, no human review, some entitlements locked (Phase 2)

Plus:

- How to *request* a tier upgrade — who to talk to, what evidence to provide
- Auto-downgrade triggers — runtime telemetry that bumps a Verified package back to Beta
- What a brand actually sees per tier — banner copy, install warning text, entitlement gating
