# Featured placement

The marketplace home has editorial slots — "Featured," "New this week," category hero rows. This page covers how those slots get filled and what you can do to land in one.

This page covers:

- Editorial slots vs algorithmic feeds — which is which, what feeds each
- How OPVS picks features in Phase 1 — manual editorial; no self-serve promote-button yet
- What makes a package feature-worthy — quality of marketing overlay, recency, install velocity, novelty of capability
- The "More from this vendor" carousel — appears on every package detail page in your scope; nothing to do, you're auto-eligible
- "Similar packages" — algorithmic in Phase 2, based on category + entitlement overlap
- Public catalog SEO — `llms.txt` + `agent.json` package entries (Phase 2) for AI-agent discovery in Claude Code / Cursor
