# Analytics

OPVS rolls up install counts, tool-call volume, and error rates per package and surfaces a slice of that back to you. This page covers what data you have access to and how to read it.

This page covers:

- Install count — total, active (last 30 days), new this week
- Per-tool call volume — for each method on each skill in your package
- Error rates — split by HTTP class (4xx user error vs 5xx upstream)
- Latency percentiles — p50 / p95 / p99 for outbound calls
- Ratings & reviews — aggregate and distribution
- Tier-transition signals — when telemetry would push a Verified-tier package back to Beta, you see it first
- What's *not* in the v1 surface — per-brand identifying analytics (privacy), revenue (Phase 3)
