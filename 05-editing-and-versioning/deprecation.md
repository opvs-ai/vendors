# Deprecation

Deprecating a version is the soft path: existing installs keep working, but new installs see a warning and the dashboard nudges brands toward the newer version. It's the gentler alternative to revocation.

This page covers:

- When to deprecate vs revoke — bug-free but superseded → deprecate; security issue → revoke
- How to deprecate a version — endpoint, headers, what gets flagged
- What brands see — dashboard banner, doctor warning, no agent-side disruption
- How long to support a deprecated version — your call; some vendors keep them installable for years, some pull them after 90 days
- Communicating the deprecation — CHANGELOG, customer email, in-app notice via marketing overlay
