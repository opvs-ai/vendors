# 01. Onboarding

Your first stop. You're new to OPVS, you've heard you can publish a skill on `market.opvs.ai`, and you want to know what that takes.

This section is about getting into the marketplace as a recognised vendor. It does *not* cover authoring a skill yet (that's [03-authoring/](../03-authoring/)) or how to authenticate API calls (that's [02-authentication/](../02-authentication/)). It covers the question: *who are you, what kind of vendor are you, and how do you get your signing cert?*

## Pages

- [become-a-vendor.md](become-a-vendor.md) — the path from interest to approved vendor account
- [vendor-types.md](vendor-types.md) — internal teams, partners, third-party developers, and the differences between them
- [apply-for-a-cert.md](apply-for-a-cert.md) — the ed25519 signing key flow that mints your publishing cert

## What's next

Once you have a vendor account and a cert, head to [02-authentication/](../02-authentication/) to get the partner key your CLI needs for HTTP API calls.
